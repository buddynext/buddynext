# Complete Feature Directory

Everything BuddyNext can do, and the page that documents it. This is the exhaustive index - use it to check what is possible, confirm a feature exists, or jump straight to any topic. For a friendlier starting path, see [Start Here](00-start-here.md); for goal-based walkthroughs, see the Recipes.

**(Free)** ships in the free plugin. **(Pro)** needs BuddyNext Pro. Some features are extended by an optional companion plugin, noted where relevant.
