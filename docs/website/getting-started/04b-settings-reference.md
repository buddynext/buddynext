# Settings Reference: where to configure everything

This is the map for the question "where do I change that?" Every BuddyNext admin screen is listed by the menu group it lives under, with what it controls and the page that explains it in depth. Open the WordPress admin, look under the **BuddyNext** menu, and match the screen here.

If you would rather jump straight to a setting by name, the admin has a command palette - press the shortcut shown in [Admin Overview](04-admin-overview.md) and start typing.
